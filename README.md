# The Sith Vanguard Portal

A public information portal for The Sith Vanguard, a division of The Sith Order.

## Purpose

The Sith Vanguard Portal provides public information regarding the Vanguard’s role, ranks, entry requirements, duties, resources, and structure.

The Sith Vanguard oversees the training of the Order’s tacticians and organizes offensive or defensive raids involving the Jedi.
